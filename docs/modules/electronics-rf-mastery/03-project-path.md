## Required proof by phase

### Make power visible

- Calculation, schematic, current measurement, safe fault test, temperature check, and manual fallback

### Make signals visible

- Predicted response, measured points, wiring diagram, data sample, and disconnect/recovery test

### See the air

- Sanitized SDR captures, signal classifications, controlled gain/noise comparisons, and mitigation notes

### Shape the signal

- Dimensions, model, calibrated analyzer sweep, angle/pattern test, and environmental limitations

### Integrate the system

- Architecture diagram, live demo, backup/restore, rebuild instructions, source files, fit test, and safety review

## Project selection rule

Only build a project if it does at least two things: improves Node reliability or visibility; teaches a reusable principle; produces measured evidence; creates a teaching demo; strengthens a portfolio case study; or can become a safe workshop, kit concept, or client-facing prototype.
