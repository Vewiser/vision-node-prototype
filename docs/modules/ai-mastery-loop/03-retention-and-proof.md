## Review session

Do not reread immediately.

1. Write everything remembered.
2. Answer three questions without notes.
3. Perform one small task.
4. Compare the result with the source.
5. Review only the missing material.
6. Update the mastery level and next review date.

## Scoring model

| Category | Points |
| --- | ---: |
| Plain-language explanation | 0–2 |
| Closed-book recall | 0–2 |
| Correct application | 0–2 |
| Troubleshooting and recovery | 0–2 |
| Safety and judgment | 0–2 |
| Transfer to another environment | 0–2 |
| Teach-back | 0–2 |

### Status

- 0–5: Seen
- 6–8: Developing
- 9–10: Functional
- 11–12: Strong
- 13–14: Mastered for the current scope

A score can fall after time away. That is useful information, not failure.

## Proof rules

Evidence may include:

- Sanitized notes
- Quiz score
- A command explained in plain language
- Expected versus actual result
- A safe failure and recovery record
- A recreated service
- A clean-system repeat
- A distribution or environment comparison
- A two-minute teach-back outline

Evidence must not include secrets, private identifiers, unredacted logs, client data, patient data, family data, or unsafe instructions.

## Proof 003 // AI-Assisted Systems Learner

Proof 003 requires three concepts from three different layers:

1. Linux foundation
2. Cloud or EC2
3. Networking, Docker, automation, recovery, or ethical security

For each concept, provide:

- The primary source
- Initial explanation
- AI gap analysis
- Closed-book quiz score
- First lab attempt
- One safe failure
- Recovery evidence
- Second attempt without copied commands
- A later review score
- Two-minute teach-back
- One verified AI mistake, uncertainty, or incomplete claim

## Pass standard

- [ ] Three concepts completed
- [ ] Each concept scores at least 11/14
- [ ] No safety category scores 0
- [ ] Each practical task is repeated independently
- [ ] At least one concept transfers to a second environment
- [ ] AI output is checked against primary documentation
- [ ] One AI error or limitation is documented
- [ ] All evidence is sanitized
- [ ] The operator can state what they can now do without AI

## Final explanation

Be able to say:

> I use AI to question, test and sharpen my understanding. I still read the source, attempt the work, verify the answer, recover from mistakes and prove I can repeat the skill without help.

## Graduation rule

After Proof 003, continue using the loop—but reduce AI assistance as mastery increases:

- Beginner: explanation and guided questions
- Developing: hints and quizzes
- Functional: scenario testing and review
- Strong: adversarial questions and transfer drills
- Mastered: teach-back, peer review and rare verification

The goal is not permanent dependence. The goal is better judgment and independent skill.
